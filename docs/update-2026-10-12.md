## Remaining limits

The imported official register is historical and omits street addresses. Mumbai jurisdiction ambiguity is kept explicit. Same-name records across sources may refer to the same premises and require licence/address reconciliation. Media reports are not original regulatory or court orders. No unverified accusations are automatically published. No paid service, package dependency, API key, hosted database, workflow artifact storage or hosting upgrade is introduced.

The website and offline validator load every part before displaying or validating the complete directory. This keeps the bulk update reviewable through GitHub tooling; all 692 entries and all source evidence are retained.
